# Lite Strategy, Inc. Investor Relations Concept

An independent design concept for the investor relations page of Lite Strategy, Inc. (Nasdaq: LITS). It is not the company's official site and is not affiliated with, endorsed by or approved by the company.

Figures are taken from the company's filings with the SEC (Form 10-K, 10-Q, 8-K and the proxy statement), each linked beside the item on the page. No share price or live Litecoin price is shown. Statements that come from the company's own website or releases are labelled as such and are not verified.

The page is a single self-contained HTML file with local images. Open `index.html` or visit the site.
